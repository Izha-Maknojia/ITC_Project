# ProjectX Password Manager

**ProjectX** is a simple, lightweight web application designed to help users store and manage their digital credentials in one place.

## 🚀 Features
* **Add Passwords:** Save website URLs, usernames, and passwords.
* **Data Persistence:** Uses `localStorage` so data stays saved after refreshing.
* **Delete Functionality:** Easily remove entries you no longer need.

## 🛠️ Technologies Used
*   **HTML5:** Structure of the web application.
*   **CSS3:** Custom styling with a modern, dark-themed aesthetic.
*   **JavaScript (ES6):** Logic for saving, displaying, and deleting data.
